# Examples / サンプル一覧

Run commands from the workspace root. 各サンプルは同じメッセージ API を使います。
必要環境は [Compatibility](../docs/COMPATIBILITY.md) / [互換性と対象範囲](../docs_ja/COMPATIBILITY.md) を参照してください。

## Runnable examples / 実行できるサンプル

| Command | What it demonstrates / 確認するもの |
| --- | --- |
| `node examples/quiz_room/start.mjs` | Axum + Reknot versus Fastify + JS, playable WebSocket quiz and live scoring/clock edits / 同じ画面でクイズと更新を比較（先に `npm ci --prefix examples/quiz_room/js`） |
| `cargo run -p typed_bot_host --locked` | Typed functions, persistent host history, stable handles and background reload / 型付き関数と保存後の一括更新 |
| `cargo run -p service_host --locked` | Host-owned TCP connection and Drain at message boundaries / 同じ接続の次の要求を新世代へ |
| `cargo run -p reknot --example restart --locked` | Static worker shutdown, checkpoint schema migration, shared load budget / 停止・移行の最小例 |
| `cargo run -p reknot --example managed_children --locked` | Root return waits for registered child cleanup before Restart / 子の終了待ちと切り替え |
| `cargo run -p threaded_io_host --locked` | Two DLL generations, two logic owners, bounded host I/O and TCP / 非同期サービスと複数スレッド |
| `cargo run -p contracts_host --locked` | Multi-service requirements, typed init validation, generation-owned environments / 複数サービスと型付き初期化 |
| `cargo run -p db_migration_host --locked` | Real DLLs, SQLite + host cache migration, rollback, retry and durable reopen / ホスト資源・DB の移行 |
| `cargo run -p tauri_tokio --locked` | Native DLL builds, in-window editor, Drain/Restart, counter and build failure recovery / GUI で編集・復旧 |
| `cargo run -p bevy_game_host --locked -- --verify` | Headless Bevy 0.20.1, real DLLs, frame cutover, delayed worker Restart and stale job rejection / ゲームへの最小適用 |

- [typed_bot_host](typed_bot_host/src/main.rs) + [typed_bot_logic](typed_bot_logic/src/lib.rs) +
  [typed_bot_protocol](typed_bot_protocol/src/lib.rs): enter text, `/summary`, or `/quit`.
  Edit logic and save; history stays in the host. Compilation/contract failure keeps
  the running generation. [English guide](../docs/TYPED_HANDLERS.md) / [日本語](../docs_ja/TYPED_HANDLERS.md)。
  Static mode: `cargo run -p typed_bot_host --no-default-features --features static-logic --locked`.
  [Framework bridge](typed_bot_host/examples/framework_bridge.rs):
  `cargo run -p typed_bot_host --example framework_bridge --no-default-features --features static-logic --locked`.
  Calls typed logic from a separate Tokio runtime thread and joins shutdown.
  自分用の3crate構成は `cargo run -p reknot --bin reknot-new --locked -- ../my-bot --sdk-path ./reknot` で生成できます。
- [WebSocket quiz room](../docs/QUIZ_ROOM.md) / [日本語](../docs_ja/QUIZ_ROOM.md):
  two independent rooms, shared questions/UI, persistent connections/scores across
  logic edits, typed Restart and a JS comparison adapter. Node.js 22+ and Rust stable.
- [service_host](service_host/src/main.rs) + [service_logic](service_logic/src/lib.rs):
  one client on `127.0.0.1:4000` (`REKNOT_ADDR` overrides it). Send newline-terminated
  messages; `slow` takes about five seconds. Source edits trigger synchronous builds,
  processed at message boundaries or while polling a request. Not a general async server.
- [restart](../reknot/examples/restart.rs): statically linked APIs; native loading
  is covered separately by tests. [Migration guide](../docs/RESTART_AND_MIGRATION.md) / [日本語](../docs_ja/RESTART_AND_MIGRATION.md).
- [db_migration_host](db_migration_host/src/lib.rs) + [db_migration_logic](db_migration_logic/src/lib.rs):
  builds three DLL variants, creates a fresh SQLite file under `target/db-migration-demo/`,
  verifies compatible Drain and breaking Restart, then exits. A C compiler is needed
  for bundled SQLite. [Exclusion and recovery](../docs/HOST_RESOURCE_MIGRATION.md) / [日本語](../docs_ja/HOST_RESOURCE_MIGRATION.md).
- [bevy_game_host](bevy_game_host/src/lib.rs) + [bevy_game_logic](bevy_game_logic/src/lib.rs):
  Rust 1.97.1+; `--verify` builds slow/fast native variants and exits after assertions.
  Without arguments, run at about 60 frames/s, edit the logic's `STEP` and save to
  build in the background and Restart. No renderer/window required. Only the logic's
  `src/lib.rs` is watched. The host owns ECS; the DLL sends copied messages.
  [Design, commands and verification](../docs/BEVY_GAME.md) / [日本語](../docs_ja/BEVY_GAME.md).
- [Tauri guide](../docs/TAURI_GUI_LAB.md) / [日本語](../docs_ja/TAURI_GUI_LAB.md): the historical package name `tauri_tokio`
  is retained as the example package identifier. `tauri_tokio/dist/` contains
  **handwritten UI source**, embedded by Tauri; it is not disposable build output.
  `src-tauri/gen/schemas/` is generated by `tauri-build` and ignored.

## Static logic / 静的リンク

```sh
cargo run -p service_host --release --no-default-features --features static-logic --locked
```

Uses the same `service_logic` handler and TCP host without a DLL, watcher or build
subprocess. `reload` is the default host feature; when both features are enabled,
the host uses the reload path. The static integration test invokes the linked
handler directly, including when workspace tests enable all features.

同じハンドラーを静的リンクでも使用します。ビルドモードは feature で明示的に選ぶため、
Release でも必要に応じて開発用のネイティブロードを使えます。

## Test fixtures / テスト専用

[reknot/tests/fixtures](../reknot/tests/fixtures) contains standalone
`rustc` DLL sources for independent ABI and lifecycle checks. They are not runnable
application templates and deliberately do not use the proc macros.
See [testing](../docs/TESTING.md) for their role and commands.
